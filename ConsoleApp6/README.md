# Комплект проектов — Занятие 03: Процессы

Два независимых учебных проекта для C# / .NET 8:

1. `Practical1_ProcessDispatcher` — запуск и контроль внешних процессов.
2. `Practical2_ProcessStreams` — перенаправление stdout/stderr без deadlock.

Условия заданий находятся в комментариях исходников. В каждом проекте есть
встроенные автоматические проверки без сторонних NuGet-пакетов. Запуск без
аргументов или с `--self-test` выводит для каждого сценария `[PASS]` или `[FAIL]`,
а в конце — суммарный результат. Код завершения тестового запуска: 0, если все
проверки прошли, иначе 1.

Ключевые методы намеренно оставлены с `NotImplementedException`, поэтому до
реализации тесты должны показывать FAIL. Это ожидаемое поведение стартового
учебного проекта.
