# П3


Цель: создать адаптер для старого принтера отчётов и подключить его через интерфейс.

## Стартовый код

Создайте консольный проект `Practice1_LegacyAdapter` под .NET 9 и поместите в `Program.cs` следующий код.

```

public record Report(
    string Title,
    string Body,
    DateTime CreatedAt
);

public interface IReportExporter
{
    string Export(Report report);
}

// Старый класс. Его изменять запрещено.
public class LegacyReportPrinter
{
    public string Print(string title, string body, string footer)
    {
        return $"=== {title} ===\n{body}\n{footer}";
    }
}

//
// TODO 3. Создайте конструктор, который принимает
// LegacyReportPrinter и проверяет его на null.
//
// TODO 4. Реализуйте Export(Report report).
// Проверьте report на null.
// Преобразуйте свойства отчёта в параметры Print.
// В footer добавьте дату в формате yyyy-MM-dd HH:mm.
// Верните строку, полученную от Print.

public class Program
{
    public static void Main()
    {
        Report report = new(
            "Отчёт по оборудованию",

        // TODO 7. Используйте переменную IReportExporter.
        // TODO 8. Выведите результат Export(report).
    }
}
```

## Дополнительные проверки

Нужно проверить:

- передача `null` в конструктор адаптера приводит к `ArgumentNullException`;
- передача `null` в `Export` приводит к `ArgumentNullException`;
- старый класс остался без изменений;
- основной код использует `IReportExporter`.
    

Критерий выполнения: приложение выводит корректный отчёт, а адаптер обеспечивает совместимость двух несовпадающих интерфейсов.
