```

public class MarkdownReportExporter : IReportExporter
{
    public string Export(Report report)
    {
        // TODO 1. Проверьте report на null.

        // TODO 2. Сформируйте Markdown:
        // # Заголовок

        // Текст отчёта
        //
        // Создан: yyyy-MM-dd HH:mm

}
```

Теперь замените создание экспортёра в `Main` на выбор одной из двух реализаций:

```
// Вариант 1 — старый принтер через адаптер
IReportExporter exporter =
    new LegacyReportAdapter(new LegacyReportPrinter());

// Вариант 2 — новый Markdown-экспортёр
// IReportExporter exporter = new MarkdownReportExporter();
```

Оставьте общий вызов:

```
Console.WriteLine(exporter.Export(report));
```

### Задания

Задание 1. Реализовать Markdown-экспортёр

Форматировать заголовок через `#`, отделить текст пустой строкой и добавить дату создания отчёта. Предусмотреть проверку `null`.

Задание 2. Переключить реализацию

Запустить программу с обоими экспортёрами. Убедиться, что для смены формата достаточно изменить место создания объекта.

Задание 3. Проверить независимость клиента

Добавить третий экспортёр `PlainTextReportExporter`, возвращающий обычный текст. Не менять интерфейс `IReportExporter` и строку вызова `Export`.
